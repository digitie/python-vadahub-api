# T001 검증

상태: 검증 진행. 최종 SHA·리뷰·CI·머지 결과는 실제 완료 후 추가한다.

## 실제 조사

2026-10-24 KST, Windows Python 3.14, Playwright async Chromium 149 실행.
최신 Playwright 기본 Chromium 다운로드는 CDN timeout으로 실패했다.
이미 설치된 Chromium 실행 경로를 명시해 실제 공개 UI 다운로드에 성공했다.
API 키·로그인 없이 공간 카탈로그 183 meta, 대상 4 meta와 7 layer를 확인했다.
도선항로·여객항로·관광지정보 4개 layer 총 6 ZIP을 공개 버튼으로 내려받고 CRC 및 전 행을
사전 pyshp 검사했다. 34/424/38/142/109/110건이며 source-analysis의 원문 hash와 대조한다.
여객터미널은 `dwldPosblYn=N`이고 다운로드 버튼이 없다. 원격 SHP 성공 항목이 아니다.
관광지 4번째 자료는 전체보기 버튼으로 펼친 뒤 다운로드했다.

## GDAL

사용자 추가 지시에 따라 kor-travel-geo의 ADR-005/loader를 확인했고,
WSL Ubuntu-26.04 Python의 GDAL 3.12.2로 실제 ZIP 6개 읽기를 성공했다.
GDAL feature count는 34/424/38/142/109/110으로 일치하고 각 SRS는 None이었다.
공개 UI→원문 다운로드와 GDAL 전 행 확인을 재현 도구로 다시 검증한다.
