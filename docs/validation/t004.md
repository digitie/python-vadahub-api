# T004 GDAL loader 검증

상태: 구현 검증 중. T003 머지 `d342204`에서 분기했다.

GDAL native 객체는 worker 내부에서만 사용한다. 검증된 로컬 ZIP을 ESRI Shapefile
driver로 열고, cN 필드와 CP949 TXT의 원본 columnName을 정확히 연결한다.
미확인 CRS를 추정하지 않으며 `.prj` 또는 호출자의 명시적 근거만 변환한다.
reader는 2 batch queue, batch당 4MiB 목표, feature WKB 16MiB 상한을 둔다.
단일 feature는 batch 목표보다 클 수 있다. 취소/early-close는 worker 해제까지 기다린다.

Windows Chromium과 WSL Ubuntu-26.04 GDAL 3.12.2의 분리된 live를 실행한다.
검증 실행 SHA, 새 ZIP 해시, GDAL 전 행, 리뷰2, CI 결과는 완료 후 기록한다.
