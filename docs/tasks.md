각 task는 순서대로 **독립 PR → 적대적 리뷰 2명 → live E2E → CI → 머지 확인** 후
다음 task에 착수한다. 상태: 예정 / 진행 / 검증중 / 외부제약 / 완료.
완료한 작업은 [tasks-done](tasks-done.md)으로 옮긴다.

T005E는 원천 제약을 숨기지 않기 위한 별도 항목이다. 이를 완료하지 않고 도선 실매핑 또는
여객터미널 원격 SHP 확보 완료로 보고하지 않는다. 해당 제약과 무관한 T006 이후 작업은 가능하다.
지원 범위 확대(T007)는 한 PR에 무리하게 담지 않고 조사 결과에 따라 하위 task/PR로 나눈다.
API 키 발급, ITS/node-link 구현, 운영 DB 배포는 task에 포함하지 않는다.
