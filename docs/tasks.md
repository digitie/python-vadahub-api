T005E는 원천 제약을 숨기지 않기 위한 별도 항목이다. 이를 완료하지 않고 도선 실매핑 또는
여객터미널 원격 SHP 확보 완료로 보고하지 않는다. 해당 제약과 무관한 T006 이후 작업은 가능하다.
지원 범위 확대(T007)는 한 PR에 무리하게 담지 않고 조사 결과에 따라 하위 task/PR로 나눈다.
API 키 발급, ITS/node-link 구현, 운영 DB 배포는 task에 포함하지 않는다.

T001~T008의 가능한 구현·검증·머지는 모두 완료했으며 [완료 작업](tasks-done.md)에
실제 PR/merge SHA와 증빙을 기록했다. 남은 두 항목은 외부 원천 확보 요구이며 구현 완료와
동일시하지 않는다. 관광 확장도 T007B의 검증된9종만 지원한다.

사용자 재개 지시에 따라 [남은 제약 재조사·보완 사양](remaining-sources.md)을 추가했다.
완료 기준을 낮추지 않고 공개된 보완 기능을 하위 task로 구현한다.

보완 하위 task T007A2E1(파랑 웹 통계)와 T005E1(공식 터미널 CSV76행)도 각각
PR #13/14로 머지 완료했다. 아래 두 원천 확보 요구는 이 보완 기능으로 대체하지 않는다.
도선34행은 출도착지/검토된 crosswalk가 없고, VadaHub 터미널은 여전히SHP 미제공이다.
API139 일반 원행은 통신 실패이며 날짜별 웹 통계 성공과 다르다.

2026-10-25 추가조사·다음구현은 [외부 원천 실제 연결 사양](external-resolution.md)을 따른다.
